AC_DrawingGUID_...string

Used by Common IE Marker.

Drawing's reference ID. Can be used to construct autotext with reference type autotexts (eg. "<MARKERSHEETNUMBER_R>" + AC_DrawingGUID_1)

  • AC_DrawingGUID_1: upper or center

  • AC_DrawingGUID_2: right

  • AC_DrawingGUID_3: bottom

  • AC_DrawingGUID_4: left
