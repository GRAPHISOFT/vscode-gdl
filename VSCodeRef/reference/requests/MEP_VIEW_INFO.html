MEP_VIEW_INFO

n = REQUEST("MEP_VIEW_INFO", InputParameters, MEPViewInfo)

Returns the MEP information related to the current view. Expression returns 0 and contains dummy return values (empty dictionary) if used in parameter script, causing additional warning.

Compatibility: introduced in Archicad 29.

InputParameters: (dictionary)
MEPViewInfo: (dictionary)
.floorPlanRepresentationMode: (integer) floor plan representation mode for MEP elements according to the MVO: 1 - Projected, 2 - Symbolic
.symbolicLoD: (integer) symbolic floor plan display representation's level of detail: 1 - Center line only, 2 - Center line + Outlines, 3 - Center line + Outlines + Insulation

Example: 

DICT InputParameters, MEPViewInfo
n = REQUEST ("MEP_VIEW_INFO", InputParameters, MEPViewInfo)
