MEP_ROUTE_ATTRIBUTES

n = REQUEST("MEP_ROUTE_ATTRIBUTES", InputAttributes, MEPRouteAttributes)

Returns attributes specific to the MEP routing tool. Can be used only in MEP routing. Expression returns 0 and contains dummy return values (empty dictionary) if used in parameter script, causing additional warning.

Compatibility: introduced in Archicad 27. The floorPlanAndSection and overheadLine parameters were introduced in Archicad 28. The floorPlanAndSection.symbolicLoD value was introduced in Archicad 29. In Archicad 30 the level of detail was split into six values.

InputAttributes: (dictionary) should be an empty, predefined dictionary.
MEPRouteAttributes: (dictionary) containing the following keys:
.penContour: (integer) pen index of contour
.surface: (integer) surface index of element
.symbolFill.type: (integer) fill type index of symbol fill
.symbolFill.pen: (integer) fill pen index of symbol fill
.symbolFill.bgPen: (integer) fill background pen index of symbol fill
.centerLine.bShow: (boolean) centerline visibility setting
.centerLine.linetype: (integer) line type index of centerline
.centerLine.pen: (integer) pen index of centerline
.insulation.surface: (integer) surface index of insulation
.floorPlanAndSection.cutPlanePosition: (integer) cut plane position value: 1 - At Upper Display Limit, 2 - By View Settings
.floorPlanAndSection.floorPlanDisplay: (integer) floor plan display value: 1 - Projected, 2 - Projected with Overhead, 3 - Symbolic
.floorPlanAndSection.showProjection: (integer) show projection value: 1 - To Floor Plan Range, 2 - To Absolute Display Limit, 3 - Entire Element
.floorPlanAndSection.symbolicLoD: (integer - deprecated from Archicad 30) symbolic floor plan display representation's level of detail: 1 - Center line only, 2 - Center line + Outlines, 3 - Center line + Outlines + Insulation
.floorPlanAndSection.ductRouteLoD: (integer) floor plan display representation's level of detail for Duct Routes: 1 - Schematic, 2 - Simplified, 3 - Detailed, 4 - Projected
.floorPlanAndSection.ductAcessoriesLoD: (integer) floor plan display representation's level of detail for Duct Accessories: 1 - Schematic, 2 - Simplified, 3 - Detailed, 4 - Projected
.floorPlanAndSection.pipeRouteLoD: (integer) floor plan display representation's level of detail for Pipe Routes: 1 - Schematic, 2 - Simplified, 3 - Detailed, 4 - Projected
.floorPlanAndSection.pipeAcessoriesLoD: (integer) floor plan display representation's level of detail for Pipe Accessories: 1 - Schematic, 2 - Simplified, 3 - Detailed, 4 - Projected
.floorPlanAndSection.cableCarrierLoD: (integer) floor plan display representation's level of detail for Cable Carrier Routes: 1 - Schematic, 2 - Simplified, 3 - Detailed, 4 - Projected
.floorPlanAndSection.equipmentLoD: (integer) floor plan display representation's level of detail for Equipments: 1 - Schematic, 2 - Simplified, 3 - Detailed, 4 - Projected
.overheadLine.linetype: (integer) line type index of overhead line
.overheadLine.pen: (integer) pen index of overhead line

Example: 

DICT InputAttributes, MEPRouteAttributes
n = REQUEST ("MEP_ROUTE_ATTRIBUTES", InputAttributes, MEPRouteAttributes)
