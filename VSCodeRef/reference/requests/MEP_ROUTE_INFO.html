MEP_ROUTE_INFO

n = REQUEST("MEP_ROUTE_INFO", InputParameters, MEPRouteInfo)

Returns geometrical data specific to the MEP routing tool. Can be used only in MEP routing. Expression returns 0 and contains dummy return values (empty dictionary) if used in parameter script, causing additional warning.

Compatibility: introduced in Archicad 29.

InputParameters: (dictionary)
.elemType: (integer) MEP element type. Segment = 1, Bend = 2, Transition = 3, Branch = 4
MEPRouteInfo: (dictionary) containing the following keys:
.portData: (array) descriptors of ports
.portData[n].position: (dictionary) position of the port
.portData[n].position.x: (float)
.portData[n].position.y: (float)
.portData[n].position.z: (float)
.portData[n].directionVector: (dictionary) unitvector pointing away from the port
.portData[n].directionVector.ux: (float)
.portData[n].directionVector.uy: (float)
.portData[n].directionVector.uz: (float)
.portData[n].widthVector: (dictionary) unitvector pointing sideways of the port
.portData[n].widthVector.ux: (float)
.portData[n].widthVector.uy: (float)
.portData[n].widthVector.uz: (float)
.portData[n].width: (float) width of the port
.portData[n].height: (float) height of the port
.portData[n].wallThickness: (float) wall thickness of the port
.portData[n].flangeSize: (float) size of the flange
.portData[n].depth: (float) depth of the connector
.portData[n].length: (float) length of the port
.portData[n].isConnected: (boolean) True if connected to any other port
.portData[n].class: (integer) Duct = 1, Pipe = 2, CableCarrier = 3
.portData[n].gender: (integer) Unisex = 0, Male = 1, Female = 2
.portData[n].shape: (integer) Rectangular = 1, Circular = 2, Oval = 3, UShape = 4
.portData[n].visibility: (boolean) True if port is visible
.portData[n].style: (integer) NoConnector = 1, Flanged = 2, Overlap = 3
.position: (dictionary) position of the element within the local coordinate system
.position.x: (float)
.position.y: (float)
.position.z: (float)
.directionVector: (dictionary) unitvector determining the direction of the element
.directionVector.ux: (float)
.directionVector.uy: (float)
.directionVector.uz: (float)
.widthVector: (dictionary) unitvector pointing to the side of the element
.widthVector.ux: (float)
.widthVector.uy: (float)
.widthVector.uz: (float)
.numberConnections: (integer) number of the element's ports
.hasInsulation: (boolean) element has insulation
.insulationThickness: (float) insulation thickness
.straightLength: (float) length of the element (Only filled for Segment and Transition elements)
.transitionOffsetY: (float) offset of the second port along the width axis (Only filled for Transition elements)
.transitionOffsetZ: (float) offset of the second port along the height axis (Only filled for Transition elements)
.bendAngle: (float) angle of bend (Only filled for Bend elements)
.bendRadius: (float) radius of bend (Only filled for Bend elements)
.branchAngle: (float) angle of branch (Only filled for tee elements)
.branchOffset: (float) offset of the branch, measured from its first port (Only filled for tee elements)

Example: 

DICT InputParameters, MEPRouteInfo
n = REQUEST ("MEP_ROUTE_INFO", InputParameters, MEPRouteInfo)
