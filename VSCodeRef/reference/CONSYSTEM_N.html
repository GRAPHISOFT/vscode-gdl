ConSystem_nstring

MEP System of the connection identified by the index after the underscore (marked by letter n in the parameter name).

MEP Systems can be created, edited or deleted in the MEP Systems Dialog in Archicad. These systems are identified by their name, and are available for certain domains (ductwork, pipework, cable tray). Several MEP operations require the coincidence of the MEP Systems of the elements.

When this parameter is set from Archicad, the GDL should set the new value into MEP_StrConnectionData.

Maximum value of n is 18.
